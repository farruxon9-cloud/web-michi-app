# Slides Generation Rules

## 1. Visual Card Progression
- Build slides as sequential slides inside a carousel block:
  ```carousel
  [Slide Content 1]
  <!-- slide -->
  [Slide Content 2]
  ```
- Each slide should contain a heading, brief scannable bullet points, and code examples if relevant.

## 2. Diagram Integration
- Embed Mermaid.js diagrams to illustrate visual flows, sequence cycles, and system components between slides.
