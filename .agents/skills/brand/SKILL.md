# Brand Identity Guidelines

## 1. Brand Colors
- **Primary Indigo:** `#5E5CE6` / `#5A55EA` (vibrant, modern, clean).
- **Secondary Purple:** `#AF52DE` (premium accent).
- **Accent Teal:** `#00F0FF` / `#30D158` (active states, verified status).

## 2. Logo Formatting
- Logo icons should use linear gradients from primary to secondary.
- Always attach the beta or version tags (e.g. `BETA` or `SETUP`) as small bold labels with high-contrast pill styling.
