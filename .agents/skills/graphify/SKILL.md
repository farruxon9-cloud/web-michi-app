# Graphify Codebase Knowledge Graph Skill

Use this skill to query and inspect the Michi App codebase knowledge graph, reducing context token usage by over 70%.

## Available Knowledge Artifacts
1. **`CODEBASE_GRAPH.md`**: Token-optimized architectural map generated by Node.js AST parser.
2. **`graphify-out/GRAPH_REPORT.md`**: Full multi-community knowledge graph report with God Nodes and 2,138 parsed symbol nodes.
3. **`graph.html` / `graphify-out/graph.html`**: Interactive visual graphs for browser inspection.

## Commands
- Run native JS AST generator:
  ```bash
  node scripts/generate_graphify.js
  ```
- Run Graphify CLI incremental scan:
  ```bash
  /Users/kanoatovfarrux/anaconda3/bin/graphify extract ./ --code-only
  ```
