# Japanese Language Engine Specification

## Features & Dictionary Specs
- **JLPT N1-N5 Vocabulary DB**: Indexed list of 10,000+ words with Uzbek/English translations.
- **Furigana Generator**: Maps Kanji characters to Hiragana / Katakana readings.
- **Polite Keigo Formatter**: Converts plain Japanese sentences to Sonkeigo / Kenjougo / Teineigo business forms.
