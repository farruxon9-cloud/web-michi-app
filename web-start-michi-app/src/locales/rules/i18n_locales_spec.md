# i18n Locales Specification

## Key Namespaces
- `nav`: Top/Bottom navigation tab labels.
- `jobs`: Job search filters, licenses, salaries.
- `academy`: School listings, station names, course fees.
- `nav_jdm`: GPS map, speed camera alert prompts, lane guidance instructions.
- `profile`: User settings, referral codes, resume fields.
- `michi`: Voice assistant activation chips and responses.
