## Amalga Oshirilgan O'zgarishlar
1. Desktop header o'rtasiga "Ish, maktab yoki marshrutni qidiring..." universal qidiruv paneli qo'shildi.
2. Header balandligi responsive qilindi (Mobil: 56px, Desktop: 64px).
3. O'ng tomonga bildirishnoma zangi (Unread indicator badge) va tezkor til tanlash dropdown joylashtirildi (`uz`, `ja`, `en`, `ru`, `vi`, `ne`, `zh`).
4. Kichik mobil ekranlarda (< 380px) logo matni avtomatik yashirilib, faqat ikonka qoldirildi.
