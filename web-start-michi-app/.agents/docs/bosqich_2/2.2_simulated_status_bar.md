# Bosqich 2.2: Simulated iOS Status Bar ni Olib Tashlash / Moslashtirish

## Vazifa va Tavsif
App.jsx ichida HTML/CSS bilan chizilgan sun'iy iOS status barni (soat, 5G, batareya, Dynamic Island notch) web brauzerda yashirish va faqat Capacitor native ilovalarda ko'rsatish. Web rejimda soat interval'ini to'xtatish.

## O'zgartirilgan Fayllar
- [`src/App.jsx`](file:///Users/kanoatovfarrux/michiappforjapan/web-start-michi-app/src/App.jsx)
- [`src/App.css`](file:///Users/kanoatovfarrux/michiappforjapan/web-start-michi-app/src/App.css)

## Amalga Oshirilgan O'zgarishlar
1. `App.jsx` da `.mobile-status-bar` shartli ko'rsatilishga o'tkazildi: `Capacitor.isNativePlatform()`.
2. Web brauzerda iOS status bari va notch simulyatsiyasi o'rniga `padding-top: env(safe-area-inset-top, 0px)` safe area kiritildi.
3. Web rejimda har sekundda ishlaydigan `clockTime` `setInterval` taymeri to'xtatildi.

## Tekshirish va Natija
- Web brauzerda soat va batareya simulyatori ko'rinmaydi, resurslar tejaldi.
