# Bosqich 2.3: Desktop Sidebar Navigatsiya (SideNav)

## Vazifa va Tavsif
Mobilda pastki navigatsiya (BottomNav), desktop va planshetda esa chap tomondagi vertikal sidebar (SideNav) navigatsiyasini ko'rsatish.

## Amalga Oshirilgan O'zgarishlar
1. Screen size'ni kuzatuvchi custom React hook `useMediaQuery.js` yaratildi.
2. Glassmorphism va silliq aktiv indikatorga ega `SideNav.jsx` va `SideNav.css` komponenti yaratildi.
3. `SideNav` o'z ichiga Logo, Navigatsiya tugmalari, Profil karta, Michi AI assistent vidjeti va Dark/Light tema almashish moslamasini oldi.
4. Planshetlarda (768px - 1199px) 72px faqat ikonkali yig'ilgan rejim, desktopda (≥ 1200px) 260px to'liq rejim ishlaydi.
5. `App.jsx` da shartli renderlash yo'lga qo'yildi: `{isDesktop ? <SideNav /> : <BottomNav />}`.

## Tekshirish va Natija
- Desktop va tabletlarda vertikal SideNav muvaffaqiyatli ishlamoqda.
