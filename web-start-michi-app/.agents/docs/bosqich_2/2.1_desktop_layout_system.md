# Bosqich 2.1: Desktop/Tablet Layout Tizimi (iPhone Ramkasini Olib Tashlash)

## Vazifa va Tavsif
Desktop brauzerlarda `#root` konteynerining o'zgarmas 430×880px iPhone ramkasi va atrofdagi simulyatsiya soya borderini olib tashlash. Ekranni to'liq viewport kengligigamoslashtirish.

## O'zgartirilgan Fayllar
- [`src/index.css`](file:///Users/kanoatovfarrux/michiappforjapan/web-start-michi-app/src/index.css)

## Amalga Oshirilgan O'zgarishlar
1. Desktop view-portdagi fixed `#root` 430px max-width chegarasi va iPhone ramkasi olib tashlandi.
2. Responsive breakpointlar joriy qilindi:
   - **Mobil (< 768px):** Bir ustunli to'liq ekran
   - **Planshet (768px – 1199px):** Ikki ustunli (sidebar + content)
   - **Desktop (≥ 1200px):** Uch zonali (sidebar + content + panel)
3. CSS `:root` o'zgaruvchilari kiritildi: `--sidebar-width: 260px`, `--content-max-width: 1200px`, `--layout-max-width: 1440px`.

## Tekshirish va Natija
- Ekranda iPhone ramkasi yo'qoldi, ilova to'liq desktop o'lchamda ochilmoqda.
