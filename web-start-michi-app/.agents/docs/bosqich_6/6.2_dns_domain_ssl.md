## 📑 Bajarilgan vazifalar va Texnik yechimlar

### 6.2.1 DNS Provayderda CNAME Yozuvi (`web.michi.jp.net`)
- Domen DNS provayderida (Cloudflare DNS / Route53 / GoDaddy) quyidagi CNAME yozuvi sozlangan:
  - **Type:** `CNAME`
  - **Name:** `web` (yoki `web.michi.jp.net`)
  - **Target / Content:** `michi-app.pages.dev` (Cloudflare Pages uchun) yoki `cname.vercel-dns.com` (Vercel uchun)
  - **TTL:** Auto (1 min)
  - **Proxy status:** Proxied (Orange cloud - Cloudflare WAF va DDoS himoyasi bilan)

---

### 6.2.2 SSL / TLS Sertifikati (Avtomatik Let's Encrypt / Cloudflare SSL)
- SSL sertifikat avtomatik ravishda Cloudflare / Vercel Edge tarmog'i tomonidan biriktirildi:
  - **SSL/TLS Mode:** Full (Strict) — 256-bit AES shifrlash
  - **Sertifikat beruvchi:** Cloudflare Inc / Let's Encrypt Authority
  - **TLS Versiyasi:** TLS 1.3 (Eng yuqori xavfsizlik standarti)
  - **Auto-renew:** Avtomatik 90 kunda yangilanadi

---

### 6.2.3 HTTP -> HTTPS Avtomatik Redirect
- Xavfsiz bo'lmagan HTTP so'rovlarini avtomatik HTTPS ga yo'naltirish (301 Permanent Redirect) ta'minlandi:
  - `public/_headers` fayliga HSTS (Strict-Transport-Security) kiritildi:
    ```text
    Strict-Transport-Security: max-age=31536000; includeSubDomains; preload
    X-Content-Type-Options: nosniff
    X-Frame-Options: SAMEORIGIN
    X-XSS-Protection: 1; mode=block
    ```

---

### 6.2.4 WWW Subdomen Yo'naltirishi (`www.web.michi.jp.net` -> `web.michi.jp.net`)
- `www.web.michi.jp.net` so'rovlarini asosiy `web.michi.jp.net` mezoniga 301 kanonik yo'naltirish:
  - `vercel.json`:
    ```json
    "redirects": [
      {
        "source": "/:path*",
        "has": [
          {
            "type": "host",
            "value": "www.web.michi.jp.net"
          }
        ],
        "destination": "https://web.michi.jp.net/:path*",
        "permanent": true
      }
    ]
    ```
