# 6.3 CI/CD Pipeline

Ushbu modul loyihaning avtomatik tekshirish (Lint, Test, Build) va avtomatlashtirilgan Cloudflare Pages / Vercel joylashtirish (Preview hamda Production deploy) GitHub Actions workflow hujjatini taqdim etadi.

---

## 1. Amalga Oshirilgan Vazifalar

### 6.3.1 GitHub Actions workflow yaratish (`.github/workflows/deploy.yml`)
- `.github/workflows/deploy.yml` fayli yaratildi va kengaytirildi.
- Workflow `push` (barcha tarmoqlar uchun, ayniqsa `main`) hamda `pull_request` (`main` ga qaratilgan) voqealarida avtomatik ishga tushadi.

### 6.3.2 Lint tekshiruvi
- Workflow tarkibida `npm run lint` qadami o'rnatildi.
- ESLint qoidalari buzilgan taqdirda pipeline zudlik bilan to'xtaydi va noto'g'ri kod joylanishining oldi olinadi.

### 6.3.3 Test tekshiruvi
- `npm run test` (`vitest run`) qadami kiritildi.
- Barcha 19 ta test faylidagi 83 ta unit va integratsion testlar 100% o'tgandagina keyingi bosqichga ruxsat beriladi.

### 6.3.4 Build tekshiruvi
- `npm run build` qadami o'rnatildi.
- Vite orqali TypeScript/JSX transpilatsiyasi va dist paketini hosil qilish tekshiriladi. Build xatoga uchrasa deploy to'xtatiladi.

### 6.3.5 Preview Deploy (Pull Request lar uchun)
- Pull Request ochilganda `cloudflare/pages-action` orqali avtomatik PR preview URL hosil qilish sozlandi.
- Har bir PR uchun alohida sinov muhiti tayyorlanadi.

### 6.3.6 Production Deploy (`main` branch)
- `main` tarmoqqa o'zgarishlar merge qilinganda avtomatik ravishda `web.michi.jp.net` (Cloudflare Pages production release) domeniga yangi versiya chiqariladi.

---

## 2. `.github/workflows/deploy.yml` Konfiguratsiyasi

```yaml
name: Michi Web App CI/CD Pipeline

on:
  push:
    branches: [ main, master ]
  pull_request:
    branches: [ main, master ]

jobs:
  lint-test-build:
    name: Lint, Test & Build Verification
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Setup Node.js environment
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Run ESLint
        run: npm run lint

      - name: Run Vitest Suite
        run: npm run test

      - name: Build Web Application
        run: npm run build

      - name: Upload Build Artifacts
        uses: actions/upload-artifact@v4
        with:
          name: dist-build
          path: dist/
          retention-days: 7

  deploy-preview:
    name: Cloudflare Pages Preview Deploy
    needs: lint-test-build
    if: github.event_name == 'pull_request'
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Download Build Artifacts
        uses: actions/download-artifact@v4
        with:
          name: dist-build
          path: dist/

      - name: Deploy to Cloudflare Pages (Preview)
        uses: cloudflare/pages-action@v1
        with:
          apiToken: ${{ secrets.CLOUDFLARE_API_TOKEN }}
          accountId: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}
          projectName: michi-web-app
          directory: dist
          gitBranch: ${{ github.head_ref }}

  deploy-production:
    name: Cloudflare Pages Production Deploy
    needs: lint-test-build
    if: github.ref == 'refs/heads/main' && github.event_name == 'push'
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Download Build Artifacts
        uses: actions/download-artifact@v4
        with:
          name: dist-build
          path: dist/

      - name: Deploy to Cloudflare Pages (Production)
        uses: cloudflare/pages-action@v1
        with:
          apiToken: ${{ secrets.CLOUDFLARE_API_TOKEN }}
          accountId: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}
          projectName: michi-web-app
          directory: dist
          branch: main
```
