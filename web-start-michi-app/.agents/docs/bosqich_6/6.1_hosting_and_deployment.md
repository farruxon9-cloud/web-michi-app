## 📑 Bajarilgan vazifalar va Texnik yechimlar

### 6.1.1 Hosting Tanlash va Sozlash (Cloudflare Pages / Vercel)
- Loyihani yuqori tezlikda global tarqatish uchun Cloudflare Pages hamda Vercel platformalari uchun 100% tayyor konfiguratsiya yaratildi.
- Cloudflare Pages bepul SSL, global CDN (Kanto/Kansai edge serverlari) hamda cheksiz o'tkazuvchanlik (bandwidth) taqdim etadi.

---

### 6.1.2 GitHub Repository va CI/CD Avtomatlashtirish
- `.github/workflows/deploy.yml` fayli orqali GitHub Actions CI/CD pipeline yaratildi:
  - `main` branchiga har bir push va pull request tushganda avtomatik `npx vitest run` testlari o'tkaziladi.
  - Testlar omadli o'tsa, `npm run build` bajarilib, `dist/` produktsiya bundle'i tayyorlanadi va avtomatik Cloudflare Pages / Vercel hostingiga uzatiladi.

---

### 6.1.3 Build Sozlamalari
- **Framework Preset:** Vite / React
- **Build Command:** `npm run build`
- **Output Directory:** `dist/`
- **Node.js Versiyasi:** `20.x`

---

### 6.1.4 SPA Redirect Qoidalari (404 Xatoliklarining Oldini Olish)
- Brauzerda foydalanuvchi sahifani yangilaganda (`/jobs`, `/academy`, `/profile`, `/navigation` va b.) 404 Not Found xatosi kelib chiqmasligi uchun:
  1. `public/_redirects`:
     ```text
     /*    /index.html   200
     ```
  2. `vercel.json`:
     ```json
     {
       "version": 2,
       "rewrites": [
         {
           "source": "/(.*)",
           "destination": "/index.html"
         }
       ]
     }
     ```

---

### 6.1.5 Environment Variables Sozlash (`.env.production`)
- `.env.production` fayli yaratildi va hosting panelida kiritilishi kerak bo'lgan o'zgaruvchilar shakllantirildi:
  ```env
  VITE_APP_URL=https://web.michi.jp.net
  VITE_API_BASE_URL=https://web.michi.jp.net/api

  # Gemini AI API Keys
  VITE_GEMINI_API_KEY=your_gemini_api_key
  VITE_GEMINI_API_KEY_2=your_gemini_api_key_2

  # Webhook Integrations
  VITE_N8N_OTP_WEBHOOK_URL=http://138.197.28.114:5678/webhook/351b1de7-f29c-422c-ad21-ac6e506fa6e3
  ```
