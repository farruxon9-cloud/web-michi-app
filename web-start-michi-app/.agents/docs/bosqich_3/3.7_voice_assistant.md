# 3.7 VoiceAssistant — Responsive Moslashtirish

## Bajarilgan vazifalar:
- **3.7.1 Fullscreen overlay — responsive:**
  - Barcha qurilmalarda AI yordamchining sozlash modali va side drawer panellari to'liq ekran (`position: fixed; inset: 0; width: 100vw; height: 100vh; height: 100dvh; min-height: -webkit-fill-available; z-index: 100000;`) o'lchamini to'g'ri va xatosiz egallashi ta'minlandi.
- **3.7.2 Chat feed — desktop kengligi:**
  - Desktop ekranlarda (`≥768px`) muloqot va chat bloki (`.voice-drawer-feed`, `.michi-chat-feed`, `.speech-bubble-content`) ekranning markazida `max-width: 700px; margin: 0 auto;` o'lchamga moslashtirildi.
- **3.7.3 Input area — desktop kengligi:**
  - Desktop ekranlarda (`≥768px`) matn va dictation kiritish paneli (`.voice-drawer-input-row`, `.michi-dictation-input`, `.voice-key-form`) markazlashtirilib, `max-width: 700px; margin: 0 auto;` kenglikka o'tkazildi.
- **3.7.4 Safe-area padding — universal:**
  - Barcha mobil platformalar, iOS va Android qurilmalar uchun universal safe-area insets (`env(safe-area-inset-top)`, `env(safe-area-inset-right)`, `env(safe-area-inset-bottom)`, `env(safe-area-inset-left)`) qo'shildi.
