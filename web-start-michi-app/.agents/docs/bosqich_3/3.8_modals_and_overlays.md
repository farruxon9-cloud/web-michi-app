# 3.8 Modals va Overlays — Responsive Moslashtirish

## Bajarilgan vazifalar:
- **3.8.1 EmailOtpAuthModal — desktop markazlash:**
  - Email & OTP login modali desktop ekranlarda (`≥768px`) `max-width: 420px; margin: 0 auto;` o'lchamda ekranning markaziga to'g'ri joylashtirildi.
- **3.8.2 RoleSelect — desktop markazlash:**
  - Rol tanlash konteyneri va modali desktop ekranlarda (`≥768px`) `max-width: 500px; margin: 0 auto;` o'lcham bilan markazlashtirildi.
- **3.8.3 LanguageSelect — desktop markazlash:**
  - Til tanlash modali va menyu konteyneri desktop ekranlarda (`≥768px`) `max-width: 500px; margin: 0 auto;` bilan markazlashtirildi.
- **3.8.4 ReferralModal — responsive:**
  - Mobil ekranlarda (`<768px`): `bottom-sheet` ko'rinishida pastdan qalqib chiquvchi modal.
  - Desktop ekranlarda (`≥768px`): markazlashtirilgan glassmorphism kartochkasi (`max-width: 420px; margin: 0 auto;`).
- **3.8.5 CompleteProfile modal — responsive:**
  - Profil to'ldirish modali va kartochkalari barcha ekranlarda (`max-width: 480px; margin: 0 auto;`) markazlashtirildi.
- **3.8.6 Modal overlay: position: fixed barcha modallarda:**
  - Ilgari desktopda telefon shassisi ichidan chiqib ketadigan va scrollerga bo'ysunadigan barqarorsiz overlays o'rniga, barcha modallar va fon qatlamlari uchun `position: fixed !important; inset: 0 !important; width: 100vw !important; height: 100vh !important; z-index: 99999 !important;` universal qoidasi qo'llandi.
