# Bosqich 3.3: JobDetail (Ish tafsiloti)

## Vazifa va Tavsif
JobDetail (batafsil e'lon sahifasi) ni desktop uchun ikki ustunli layoutga o'tkazish, bento kartochkalarni desktop gridga moslash, logoni 72px qilish, ariza topshirish panelini sticky sidebar qilish hamda React Router navigatsiyasini ta'minlash.

- [`src/components/JobDetail.css`](file:///Users/kanoatovfarrux/michiappforjapan/web-start-michi-app/src/components/JobDetail.css)

## Amalga Oshirilgan O'zgarishlar
1. **Desktop Ikki Ustunli Layout:** Desktopda (≥ 768px) `.detail-main-layout` grid bo'ldi (`1fr 340px`). Chap ustunda barcha tafsilotlar scroll, o'ng ustunda kompaniya kartochkasi va harakatlar paneli.
2. **Bento Kartochkalar Grid:** Desktopda imtiyozlar va sharoitlar kartochkasi (`.db-list-rows`) 2 ustunli gridga o'tkazildi.
3. **Company Logo O'lchami:** Mobil: 50px, Default: 60px, Desktop: 72px.
4. **Sticky Apply Bar:** Mobilda bottom sticky bar, Desktopda o'ng ustun ichida sticky panel (`position: sticky; top: 80px`).
5. **Orqaga qaytish navigatsiyasi:** `useNavigate` fallback bilan URL (`/jobs/:id`) va brauzer orqaga navigatsiyasi ta'minlandi.
