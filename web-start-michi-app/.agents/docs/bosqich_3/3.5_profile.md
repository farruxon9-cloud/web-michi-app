# 3.5 Profile — Responsive Moslashtirish

## Bajarilgan vazifalar:
- **3.5.1 Profil bosh sahifa — desktop ikki ustunli:**
  - `@media (min-width: 768px)` desktop ekranda Profil bosh sahifasi ikki ustunli (2-column grid) layoutga o'tkazildi.
  - Chap ustun: foydalanuvchi avatari, ismi, profili, email tasdiq va JLPT nishonlari (`position: sticky`).
  - O'ng ustun: Rezyume kartochkasi, ma'lumotlar subkartalari, statistika kartochkalari va navigatsiya menyusi.
- **3.5.2 Contact grid — responsive:**
  - Mobil ekranlarda (`<440px`): 1 ustunli ixcham ko'rinish.
  - Tablet ekranlarda (`440px` – `1199px`): 2 ustunli setka.
  - Desktop ekranlarda (`≥1200px`): 3 ustunli kontakt va ma'lumotlar gridi.
- **3.5.3 Ariza ro'yxatlari — jadval/kartochka:**
  - Mobil ekranlarda kartochka (card) formatida.
  - Desktop ekranlarda (`≥768px`) sarlavhali to'liq jadval (`applications-table-header` + grid row) formatiga o'tkazildi.
- **3.5.4 Settings — desktop markazlashtirilgan:**
  - Desktop ekranlarda sozlamalar ekrani markazga joylashtirildi (`max-width: 600px; margin: 0 auto;`).
- **3.5.5 Resume Builder — desktop kengligi:**
  - Desktop ekranlarda (`≥1024px`) 2 ustunli split view (bo'lingan ko'rinish) joriy qilindi:
  - Chap panel (Preview): yapon rirekisho PDF preview iframe va yuklab olish harakatlari tugmalari.
  - O'ng panel (Edit): rezyume to'ldirish formasi va 5 ta bosqichli tahrirlash bloklari.
