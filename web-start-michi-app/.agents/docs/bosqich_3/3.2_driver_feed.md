# Bosqich 3.2: DriverFeed (Ish e'lonlari)

## Vazifa va Tavsif
DriverFeed ish e'lonlari ro'yxatini mobil, tablet va desktop ekranlar uchun moslashtirish. Grid kartochkalar, markazlashtirilgan qidiruv paneli, o'ng tomondan chiquvchi advanced filter sidebar va split view xarita modalini joriy qilish.

- [`src/components/DriverFeed.css`](file:///Users/kanoatovfarrux/michiappforjapan/web-start-michi-app/src/components/DriverFeed.css)

## Amalga Oshirilgan O'zgarishlar
1. **Ish Kartochkalari Grid:** Mobil: 1 ustun, Tablet: 2 ustun, Desktop: 3 ustun (`grid-template-columns: repeat(3, 1fr)`).
2. **Horizontal Scroll -> Grid Wrap:** Desktopda barcha chiplar va segmentlar `flex-wrap: wrap` ga o'tkazildi.
3. **Qidiruv va Segment paneli:** Desktopda `max-width: 600px` (desktopda `680px`) da markazlashtirildi.
4. **Advanced Filter Modal:** Desktopda o'ng paneldan silliq chiquvchi (`420px` kenglikda) drawer sidebar yaratildi.
5. **Xarita Modal Split View:** Desktopda chap tomonda e'lonlar ro'yxati va o'ng tomonda interaktiv Leaflet xaritasi split view rejimida ishlaydi.
6. **Rasm o'lchamlari:** Mobil: 105px, Tablet: 140px, Desktop: 180px.
7. **Filter Chips Hover Effects:** `@media (hover: hover)` orqali hover va transform transition efektlari kiritildi.
