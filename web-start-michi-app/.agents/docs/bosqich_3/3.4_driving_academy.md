# Bosqich 3.4: DrivingAcademy (Avtomaktablar)

## Vazifa va Tavsif
DrivingAcademy (Avtomaktablar) komponentining mobil, tablet va desktop variantlarini moslashtirish: Maktab kartochkalari gridi, desktop 2-ustunli detail view, markazlashtirilgan qidiruv va responsive kurs narxlari jadvalini tatbiq etish.

- [`src/components/DrivingAcademy.css`](file:///Users/kanoatovfarrux/michiappforjapan/web-start-michi-app/src/components/DrivingAcademy.css)

## Amalga Oshirilgan O'zgarishlar
1. **Maktab Kartochkalari Grid:** Mobil (< 768px): 1 ustun, Tablet (768px – 1199px): 2 ustun, Desktop (≥ 1200px): 3 ustun (`grid-template-columns: repeat(3, 1fr)`).
2. **Detail View — Desktop Ikki Ustunli:** Desktopda `.school-detail-main-layout` yaradilib, Chap ustunda maktab tafsilotlari, kurslar, narxlar jadvali va tavsif; O'ng ustunda esa yopishqoq ariza va harakatlar paneli (`.school-detail-right-col` sticky bar).
3. **Qidiruv va Filter:** Desktop va tabletlarda `.search-row` `max-width: 700px` o'lchamda markazlashtirildi.
4. **Kurs Narxlari Jadvali (Responsive Table):**
   - **Mobil (< 768px):** Ixcham `.course-price-cards-mobile` kartochka ko'rinishi.
   - **Desktop (≥ 768px):** Strukturalangan `.academy-pricing-table` to'liq jadval ko'rinishi (Kurs nomi, muddati, dars tillari, chegirma va narxi).
