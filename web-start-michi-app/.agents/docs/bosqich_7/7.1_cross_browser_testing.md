# 7.1 Cross-Browser Sinov

Ushbu modul loyihaning barcha asosiy ishchi stoli (Desktop) hamda mobil (iOS / Android) brauzerlarida bir xil pixel-perfect va funksional ishlashini ta'minlash va sinovdan o'tkazish natijalarini jamlaydi.

---

## 1. Amalga Oshirilgan Vazifalar va Sinov Natijalari

### 7.1.1 Chrome Desktop (Mac / Windows)
- **Tekshiruv yo'nalishlari**: Grid va Flexbox tartibi, sichqoncha bilan uzluksiz hover va transition effektlari, dark/light mode almashinuvi.
- **Natija**: Muvaffaqiyatli. CSS o'zgaruvchilar va fluid typography (`clamp()`) Chrome Blink dvigatelida to'liq to'g'ri aks etadi.

### 7.1.2 Safari Desktop (macOS)
- **Tekshiruv yo'nalishlari**: Glassmorphism va `backdrop-filter` effektlari, `-webkit-font-smoothing` va typografiya renderlanishi.
- **Natija**: Muvaffaqiyatli. Barcha CSS fayllarga `-webkit-backdrop-filter` qo mezonlari kiritilgan va shaffof shisha effekti uzluksiz ishlaydi.

### 7.1.3 Firefox Desktop (Windows / Linux)
- **Tekshiruv yo'nalishlari**: Custom scrollbar (`scrollbar-width: thin;`, `scrollbar-color`), CSS Grid layout mosligi.
- **Natija**: Muvaffaqiyatli. Global `src/index.css` faylida Firefox uchun maxsus `scrollbar-width` va `scrollbar-color` standartlari o'rnatildi.

### 7.1.4 Safari iOS (iPhone / iPad)
- **Tekshiruv yo'nalishlari**: Safe-area padding (`env(safe-area-inset-top)`, `env(safe-area-inset-bottom)`), double-tap zoomning oldini olish (`touch-action: manipulation`), PWA `apple-touch-icon` hamda web-app status bar.
- **Natija**: Muvaffaqiyatli. iPhone ramkasiz qurilmalarida status bar va Home bar joylashuvlari to'g'ri hisoblangan.

### 7.1.5 Chrome Android
- **Tekshiruv yo'nalishlari**: Sensorli ekran bilan navigatsiya, PWA o'rnatish taklifi (`manifest.webmanifest`, `theme_color`), fond rendering.
- **Natija**: Muvaffaqiyatli. Web App Manifest va Service Worker to'liq precache va pwa rejimida ishlaydi.

### 7.1.6 Samsung Internet (Android)
- **Tekshiruv yo'nalishlari**: Dark mode `color-scheme` qo'llab-quvvatlanishi, yapon shriftlari (`Noto Sans JP`, `Sawarabi Gothic`).
- **Natija**: Muvaffaqiyatli. `<meta name="color-scheme" content="dark light">` tagi va font fallback tartibi tufayli bir xil matn ko'rinishi ta'minlandi.

### 7.1.7 Edge Desktop (Windows)
- **Tekshiruv yo'nalishlari**: High contrast mode (`forced-colors`), layout va unumdorlik.
- **Natija**: Muvaffaqiyatli. `forced-colors: active` media so'rovi orqali Windows yuqori kontrast rejimida tugmalar va matnlar ajralib turadi.

## 2. Kiritilgan Cross-Browser CSS Reset Standartlari

```css
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
  -webkit-tap-highlight-color: transparent;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  text-rendering: optimizeLegibility;
  scrollbar-width: thin;
  scrollbar-color: rgba(140, 140, 160, 0.35) transparent;
}

/* WebKit Scrollbar Reset (Chrome, Safari, Edge, Samsung Internet) */
::-webkit-scrollbar {
  width: 6px;
  height: 6px;
}
::-webkit-scrollbar-track {
  background: transparent;
}
::-webkit-scrollbar-thumb {
  background: rgba(140, 140, 160, 0.35);
  border-radius: 9999px;
}
::-webkit-scrollbar-thumb:hover {
  background: rgba(140, 140, 160, 0.65);
}
```
