# 4.1 CSS Normalization va Reset Kengaytirish

## Bajarilgan vazifalar:
- **4.1.1 Font rendering bir xillashtirish (`src/index.css`):**
  - Universal reset `*, *::before, *::after` ga `-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscale; text-rendering: optimizeLegibility;` qoidalari qo'shildi. Barcha matnlar iOS, macOS va Windows brauzerlarida tekis va silliq render bo me'yorga keltirildi.
- **4.1.2 Input/Button normallashtirish (`src/index.css`):**
  - Form elementlariga (`button, input, select, textarea`) `appearance: none; -webkit-appearance: none; -moz-appearance: none;` va shriftdan meros olish qoidalari berildi. Safari, Chrome va Firefox'dagi noo'rin standart brauzer dizaynlari (masalan, iOS standart ichki soyalari) olib tashlandi.
- **4.1.3 Touch-action sozlash (`src/index.css`):**
  - `html, body, #root, button, a, input, select, textarea, [role="button"]` barcha interaktiv elementlarga `touch-action: manipulation;` o'rnatildi. Mobil qurilmalarda double-tap zoom 300ms kechikishi bartaraf etildi.
- **4.1.4 Color-scheme meta tag (`index.html`):**
  - `index.html` `head` qismiga `<meta name="color-scheme" content="dark light" />` teg qo'shildi. Brauzerlarga loyihaning tungi va kunduzgi rejimni qo'llab-quvvatlashi bildirildi.
- **4.1.5 Forced-colors media query (`src/index.css`):**
  - Windows High Contrast rejimi uchun `@media (forced-colors: active)` qo'shildi. Kontrast rejim yoqilganda tugmalar va kiritish maydonlari `ButtonText`, `HighlightText` va `Highlight` tizim ranglari orqali aniq ko'rinishi ta'minlandi.
