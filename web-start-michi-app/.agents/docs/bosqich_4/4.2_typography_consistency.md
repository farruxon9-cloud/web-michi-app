# 4.2 Tipografiya Konsistentligi

## Bajarilgan vazifalar:
- **4.2.1 Responsive font-size tizimi:**
  - CSS custom properties va `clamp()` funksiyasi yordamida responsive (fluid) tipografiya tizimi yo'lga qo'yildi:
    - `--font-size-base: clamp(14px, 1.2vw + 11px, 17px);`
    - `--font-size-sm: clamp(12px, 0.8vw + 10px, 14px);`
    - `--font-size-h1: clamp(24px, 3.5vw + 10px, 36px);`
    - `--font-size-h2: clamp(20px, 2.5vw + 10px, 28px);`
    - `--font-size-h3: clamp(16px, 1.8vw + 10px, 22px);`
    - `--font-size-h4: clamp(14px, 1.4vw + 10px, 18px);`
- **4.2.2 Yapon shrift optimizatsiyasi:**
  - `Sawarabi Gothic` hamda `Noto Sans JP` yapon shriftlari uchun Google Fonts so'rovlariga `&display=swap` va subset parametrlari o'rnatildi. Shrift yuklangunga qadar matn darhol ko'rinishi ta'minlandi (FOIT oldi olindi).
- **4.2.3 Font fallback ketma-ketligi:**
  - Har bir operatsion tizimda (iOS, macOS, Windows, Android, Linux) bir xil va optimal render bo'lishi uchun universal fallback tizimi yo'lga qo me'yorga keltirildi:
    - `--font-family: -apple-system, BlinkMacSystemFont, "SF Pro Rounded", "SF Pro Text", "Plus Jakarta Sans", "Inter", "Nunito", "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans JP", "Sawarabi Gothic", sans-serif;`
- **4.2.4 Line-height standarti:**
  - Barcha asosiy matnlar, xabarlar va form elementlari uchun `line-height: 1.5;`, sarlavhalar uchun esa `line-height: 1.25;` standarti o'rnatildi.
- **4.2.5 Letter-spacing standarti:**
  - Sarlavhalarga (`h1`–`h6`) modern ko'rinish va o'qish qulayligi beruvchi `letter-spacing: -0.02em;`, asosiy matn va kontentlarga esa `letter-spacing: normal;` standarti biriktirildi.
