## 📑 Bajarilgan vazifalar va Texnik yechimlar

### 4.3.1 Rasmlarni responsive qilish (`max-width: 100%; height: auto;`)
- Barcha `<img>`, `<video>`, `<iframe>`, `<canvas>`, va `<svg>` media elementlari uchun `index.css` ga universal reset qo'shildi:
  ```css
  img, video, iframe, canvas, svg {
    max-width: 100%;
    height: auto;
  }
  ```
- Bu o'lcham overrun va gorizontal scroll (overflow-x) muammolarining oldini oladi.

---

### 4.3.2 Aspect-ratio qo'shish (Bo'sh joy oldindan ajratish / CLS oldini olish)
- Kartochka rasmlari, avatar va bannerlar uchun CSS `aspect-ratio` xususiyati qo'shildi:
  ```css
  /* Kartochka rasmlari uchun 16:9 nisbat */
  .card-img,
  .job-card-thumb,
  .school-card-thumb,
  .article-thumb,
  .truck-image-placeholder {
    aspect-ratio: 16 / 9;
    object-fit: cover;
    width: 100%;
    background-color: var(--color-bg-secondary, #1e293b);
  }

  /* Avatar rasmlari uchun 1:1 kvadrat nisbat */
  .avatar-img,
  .user-avatar,
  .profile-avatar-img,
  .driver-avatar {
    aspect-ratio: 1 / 1;
    object-fit: cover;
    border-radius: 50%;
  }

  /* Banner rasmlari uchun 21:9 (desktop) / 16:9 (mobil) */
  .banner-img,
  .hero-banner-img {
    aspect-ratio: 21 / 9;
    object-fit: cover;
    width: 100%;
  }

  @media (max-width: 640px) {
    .banner-img,
    .hero-banner-img {
      aspect-ratio: 16 / 9;
    }
  }
  ```

---

### 4.3.3 Object-fit: cover va contain tekshirish
- Avatar, banner hamda kartochka rasmlarida tasvirning buzilib (stretch) qolmasligi uchun `object-fit: cover` qo'llanildi.
- Utility klasslar: `img.cover { object-fit: cover; }` va `img.contain { object-fit: contain; }`.

---

### 4.3.4 WebP formatini qo'llab-quvvatlash va Fallback
- `picture` konteyneri hamda WebP rasmlar uchun stil qo'shildi:
  ```css
  picture {
    display: block;
    width: 100%;
  }
  ```
- HTML `<picture>` tagi orqali brauzer WebP formatini qo'llab-quvvatlasa WebP, aks holda PNG/JPG yuklaydi.

---

### 4.3.5 Lazy loading barcha rasmlarga (`loading="lazy"` va IntersectionObserver)
- Profile va JobDetail kabi barcha asosiy komponentlardagi `<img>` taglariga `loading="lazy"` atributi qo'shildi.
- Transformativ lazy loading animatsiyasi (fade-in):
  ```css
  img[loading="lazy"] {
    opacity: 0;
    transition: opacity 0.3s ease-in-out;
  }

  img[loading="lazy"].loaded,
  img[loading="lazy"]:not([src=""]) {
    opacity: 1;
  }
  ```
- Maxsus `LazyVehicleImage.jsx` komponenti `IntersectionObserver` orqali dinamik yuklanishni boshqaradi.
