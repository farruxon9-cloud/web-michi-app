# Bosqich 1.3: PWA Manifest va Servis Uskunalari Sozlamalari

## Vazifa va Tavsif
`vite.config.js` ichidagi `VitePWA` plagini uchun PWA manifest atributlarini yangilash, mos doiralar (scope), identifikator (id), kategoriyalar va PWA install dialog uchun screenshot'lar qo'shish.

## O'zgartirilgan Fayllar
- [`vite.config.js`](file:///Users/kanoatovfarrux/michiappforjapan/web-start-michi-app/vite.config.js)

## Amalga Oshirilgan O'zgarishlar
1. `id`: `'michi-web-app'`
2. `start_url`: `'/'` va `scope`: `'/'`
3. `display_override`: `['window-controls-overlay', 'standalone', 'minimal-ui']`
4. `categories`: `['business', 'navigation', 'education']`
5. PWA tezkor havolalari (`shortcuts`): Jobs, Academy, Navigation.
6. PWA ikonkalari: `pwa-192x192.png`, `pwa-512x512.png`, va maskable `maskable-icon-512x512.png`.

## Tekshirish va Natija
- `vite build` va Workbox PWA manifest generator muvaffaqiyatli ishga tushdi.
