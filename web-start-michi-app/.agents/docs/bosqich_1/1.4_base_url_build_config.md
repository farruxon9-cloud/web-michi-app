## Vazifa va Tavsif
Vite bundler sozlamalarida `base: '/'` absolyut yo'nalishini belgilash, `package.json` da `"homepage": "https://web.michi.jp.net"`, SPA fallback uchun Cloudflare/Netlify redirect va Rolldown vendor chunk splitting'ni sozlash.

## Amalga Oshirilgan O'zgarishlar
1. `vite.config.js` da `base: '/'` absolyut yo'nalishi belgilandi.
2. `package.json` fayliga `"homepage": "https://web.michi.jp.net"` qo'shildi.
3. `public/_redirects` yaratilib, barcha SPA yo'nalishlari `/* /index.html 200` ga yo'naltirildi.
4. `sourcemap: false` qilinib production hajmi kichraytirildi.
5. `manualChunks(id)` funksiyasi orqali React, Lucide-Icons va MapLibre-GL kutubxonalari alohida vendor chunk'larga ajratildi.
