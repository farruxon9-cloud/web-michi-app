# Bosqich 1.2: Viewport va SEO Meta Taglar

## Vazifa va Tavsif
`index.html` fayliga mobil va desktop qurilmalar uchun zaruriy meta taglar, Open Graph (OG), Twitter Card, Canonical URL, Apple PWA metas hamda Google WebApplication JSON-LD sxemasini qo'shish.

## O'zgartirilgan Fayllar
- [`index.html`](file:///Users/kanoatovfarrux/michiappforjapan/web-start-michi-app/index.html)

## Amalga Oshirilgan O'zgarishlar
1. Viewport meta tagiga `viewport-fit=cover`, `width=device-width, initial-scale=1.0` qo'shildi.
2. `theme-color`: `#0A84FF` (Dark mode variant: `#000000`).
3. Open Graph va Twitter card meta taglari kiritildi (`og:title`, `og:description`, `og:image`, `og:url: https://web.michi.jp.net/`).
4. Canonical tag (`https://web.michi.jp.net/`) va Apple mobile web app capabile taglari joylashtirildi.
5. Google Fonts (`Inter`, `Outfit`) va JSON-LD `WebApplication` sxemasi `index.html` ga birlashtirildi.

## Tekshirish va Natija
- HTML validatsiyasi va SEO meta taglarining barchasi muvaffaqiyatli ishlaydi.
