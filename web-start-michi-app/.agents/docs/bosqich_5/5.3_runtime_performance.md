### 5.3.2 useCallback optimallashtirish
- `App.jsx` hamda boshqa asosiy sahifalarda child komponentlarga props sifatida uzatiladigan barcha asosiy state handler funksiyalari `useCallback()` bilan o'raldi:

### 5.3.3 Virtual Scrolling / Layout Containment
- Ish e'lonlari (`DriverFeed`) va Avtomaktablar (`DrivingAcademy`) ro'yxatlarida CSS `content-visibility: auto` va `contain-intrinsic-size` xususiyatlari qo'llanildi. Bu viewport'dan tashqaridagi elementlarni DOM re-flow va layout rendering bosqichidan ozod etib, 60 FPS silliq scroll imkonini beradi.

### 5.3.4 Debounce qidiruv (`src/hooks/useDebounce.js`)
- `useDebounce` maxsus React hook'i yaratildi:
  ```javascript
  import { useState, useEffect } from 'react';

  export function useDebounce(value, delay = 300) {
    const [debouncedValue, setDebouncedValue] = useState(value);

    useEffect(() => {
      const handler = setTimeout(() => {
        setDebouncedValue(value);
      }, delay);

      return () => clearTimeout(handler);
    }, [value, delay]);

    return debouncedValue;
  }
  ```
- `jobSearchQuery` va `academySearchQuery` uchun 300ms debounce ulandi. Har bir klaviatura bosilganda darhol filtrlash funksiyasi chaqirilmasdan, foydalanuvchi yozishdan to'xtaganidan keyin 300ms o'tib filtrlash bajariladi.
