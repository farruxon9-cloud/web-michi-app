# Action Registry Specification

## Command Action Mapping
- **NAVIGATE**: Routes to specified screen tab (`home`, `jobs`, `academy`, `navigation`, `profile`).
- **SEARCH_JOBS**: Sets category, salary, and prefecture filters in DriverFeed.
- **START_NAVIGATION**: Passes target destination coordinates to JDMNavigation map controller.
- **CREATE_RESUME**: Initializes ResumeBuilder step wizard.
