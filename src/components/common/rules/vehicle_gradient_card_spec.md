# Vehicle Gradient Card Specification

## Layout Geometry & Positioning
- **Card Ratio**: `aspect-ratio: 16 / 9`, `border-radius: 20px`, `overflow: hidden`, `padding: 20px`.
- **Background Gradients**: Dynamic multi-stop radial gradients based on vehicle class category.
- **Title Overlay**: `font-size: 18px`, `font-weight: 800`, `color: #ffffff`.

## Button & Event Rules
- **Card Click**: Triggers vehicle detail view or selection modal.
