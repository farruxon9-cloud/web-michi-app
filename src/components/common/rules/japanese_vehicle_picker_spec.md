# Japanese Vehicle Picker Specification

## Vehicle Classes & Specs
- **Kei Truck (軽トラ)**: Max Payload 350kg, engine displacement <= 660cc.
- **2t Light Truck (2トントラック)**: Standard 2-ton payload (Futsu / Junchugata license requirement).
- **4t Medium Truck (4トントラック)**: Medium 4-ton payload (Chugata license requirement).
- **10t Heavy Truck (10トントラック / 大型)**: Heavy 10-ton payload (Oogata license requirement).
- **Tractor Trailer (トレーラー)**: Towing heavy vehicle (Kenin license requirement).

## Button & Event Rules
- **Vehicle Class Select**: Sets payload & license compatibility filter in navigation and job search engines.
