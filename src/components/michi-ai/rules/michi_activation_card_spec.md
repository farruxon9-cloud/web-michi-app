# Michi Activation Card Specification

## Layout Geometry & Positioning
- **Container**: Bento Hero Card inside Dashboard / Home grid.
- **Border Radius**: `24px`.
- **Padding**: `20px` internal padding.
- **Background**: Modern purple-indigo gradient `linear-gradient(135deg, rgba(161,51,255,0.12), rgba(139,92,246,0.06))`.
- **Border**: `1px solid rgba(161, 51, 255, 0.25)`.

## Button & Event Rules
- **Mic Voice Trigger**: Opens ambient voice listener overlay immediately.
- **Quick Action Chips**: Automatically executes pre-filled command query in Michi AI engine.
